本术语表标准化了 Rilo 文档中使用的关键术语。

## 核心术语

- 阶段：
  管道的一个阶段，例如脚本、旁白、关键帧、片段、合成、对齐字幕或烧录字幕。
- 运行状态：
  `run-state.json` 中持久化的阶段状态和运行元数据。
- 工件：
  生成的输出元数据（路径、URL、时间线、提示），持久化在 `artifacts.json` 中。
- 项目：
  `projects/<project>/` 下的命名工作区，包含配置、内容、工件、运行状态和资产。
- 重新生成：
  在有针对性的更改后重新运行一个或多个下游阶段。
- 失效：
  当上游输入更改时，将下游阶段标记为过时。
- 运行锁：
  项目级锁，防止同一项目的并发写入。

## API 术语

- 作业 API：
  `/jobs` 下的端点，用于启动运行和获取作业状态。
- 项目 API：
  `/projects` 下的端点，用于项目 CRUD、配置/内容更新、日志、工件、分析和有针对性的重新生成。
- Webhook：
  回调端点 (`/webhooks/replicate`)，接收外部预测更新。

## 文件级引用

- `config.json`：项目配置和模型选择/选项。
- `story.md`：源故事输入。
- `run-state.json`：阶段完成和运行元数据。
- `artifacts.json`：生成的输出和引用。
- `assets/`：下载/生成的媒体文件。
