本页面为阶段流程、检查点和失效提供简洁的可视化参考。

## 管道流程

```text
故事输入
   |
   v
[脚本] -> [旁白] -> [关键帧] -> [片段] -> [合成]
                                            |
                                            v
                                 [对齐字幕] (可选)
                                            |
                                            v
                                  [烧录字幕] (可选)
```

注意：
- 片段数量根据测量的旁白持续时间进行规划。
- 每个阶段在下一个阶段开始前持久化工件。

## 检查点和恢复模型

```text
run-state.json
  - 阶段完成标志
  - 状态/错误
  - 最后更新时间戳

artifacts.json
  - 脚本/语气/镜头
  - 媒体 URL/路径
  - 最终输出和字幕工件
```

恢复规则：
- 如果必需的工件存在且有效，则重用已完成的阶段。
- 如果工件缺失/无效，则从最早的必需阶段开始重新生成。

## 失效级联

```text
故事/脚本更改
  => 旁白、关键帧、片段、合成、对齐、烧录

文本到图像模型/选项更改
  => 关键帧、片段、合成、对齐、烧录

图像到视频模型/选项更改
  => 片段、合成、对齐、烧录

字幕选项更改
  => 对齐、烧录
```
