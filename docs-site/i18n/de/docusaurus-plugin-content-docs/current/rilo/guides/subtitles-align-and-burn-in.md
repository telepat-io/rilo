title: "Untertitel: Ausrichten und Einbrennen"
---

Rilo bietet optionale Untertitel-Nachbearbeitung:
- alignSubtitles: Führt ffsubsync aus, um die Sprechertext-Zeitabläufe besser abzugleichen
- burnInSubtitles: Wendet ASS-Untertitel auf das finale Medium an

Aktivieren Sie diese, wenn von nachgelagerten Plattformen immer sichtbare Untertitel benötigt werden.
