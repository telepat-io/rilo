---

Typische Projektstruktur:
- config.json
- story.md
- run-state.json
- artifacts.json
- sync.json
- analytics/
- assets/
- snapshots/

Verwenden Sie artifacts.json und run-state.json, um generierte Medien und Stufenfortschritt zu überprüfen.
