---

Qualitätsprüfungen ausführen:

```bash
npm run lint
npm test
npm run test:coverage
npm run frontend:lint
npm run frontend:build
npm run docs:build
```

Tests sind so konzipiert, dass in den Test-Suites keine Live-Inferenz und keine externe Netzwerkabhängigkeit besteht.
