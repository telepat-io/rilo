title: Ausgabeartefakte
---

Rilo-Ausgaben umfassen:
- Prompt- und Drehbuchartefakte
- Sprechertext-Ausgaben
- Schlüsselbild-Images
- Segment-Videos
- Finale zusammengesetzte Medien
- Untertiteldateien

Überprüfen:
- `projects/<project>/artifacts.json`
- `projects/<project>/run-state.json`
- Projekt-Protokoll- und Analyse-Endpunkte

Nützliche API-Endpunkte:
- `GET /projects/:project/artifacts`
- `GET /projects/:project/prompts`
- `GET /projects/:project/logs`

Für Terminologie siehe [Glossar](/reference/glossary).
