Rilo führt eine checkpointierte Medienpipeline aus:

1. Drehbuch
2. Sprechertext
3. Schlüsselbilder
4. Segmente
5. Komposition
6. Untertitel ausrichten (optional)
7. Untertitel einbrennen (optional)

Der Projektzustand wird unter `projects/<project>/` gespeichert, damit Läufe fortgesetzt und nachgelagerte Stufen sicher regeneriert werden können.

Fahren Sie fort mit:
- [Pipeline-Stufen](/guides/pipeline-stages)
- [Glossar](/reference/glossary)
